## 一次网吧赛怎么走

开场 → 第一场（老城区三个点位）→ 每打死一个，跑去下一个点位 → 三个打完：大屏亮比分 → 三选一张临场卡 → 第二场（港口和车站）→ 第三场（夜里的城）→ **第一次全赢：从网吧椅子上站起来，身边五个人也站起来——原来是职业战队** → 战队页。

被打中：叫队友 → 广告占位 → 女队友把你拉起来（第一人称动画）→ 重打这个对手。拉人用完再死 → 重打这一场（卡留着）。

## 怎么玩（0.4：谁先暴露谁死）

- 左下按住 = 缩头：躲在墙后最安全，但看不见、打不了。点一下 = 缩一下再起来，画面会变一处（找茬）。
- 镜子下面那栋楼是你，红圈是他的镜子。红圈停在你窗口上、你又露着头，锁定圈就转；转满了他瞄准你（镜片反光），这时要么抢先开枪，要么马上缩头。
- 红圈在动 = 他探着头在找你，这也是你唯一打得中他的时候。
- 右下按住屏息、松手开枪，只算打头。打空一枪 = 枪口火光，红圈直接跳到你身上。
- 狡猾型会摆头盔假人：缩头时它不挪，打中它算打空。

## 原作玩法样机

开场页「原作玩法样机」：照 2009 年《Sniper vs Sniper》（国内叫「狙击手对决」）那类对楼狙击手游的规则搭的，画面是我们自己的。望远镜看得宽不能开枪，狙击镜能开枪看得窄；他们探头就在瞄你，3 格血，60 秒。打完有一页说明它好玩在哪、毛病在哪。

## 两层成长

| | 是什么 | 留多久 |
| --- | --- | --- |
| 临场卡 | 每打完一场三选一：深呼吸、好镜子、耳机（指方向）、口香糖、消音器（打空不暴露）、诱饵头盔（替你挨一枪，他的火光照出他自己）、伪装网、护身符、快手 | 这一次网吧赛 |
| 队友 | 五个人各管一种加成（稳得快 / 指方向 / 冷静 / 快枪 / 藏得好），花奖金练级，最高 5 级 | 一直有（存档） |
| 训练基地 | 网吧角落 → 训练室 → 战队基地，奖金 ×1 / ×1.25 / ×1.5 | 一直有 |

队友名字、长相都是占位，等 Cc 定用不用剧里的人。

## 文件

| 文件 | 管什么 |
| --- | --- |
| `game.js` / `game.json` / `project.config.json` | 微信小游戏入口和设置 |
| `js/config.js` | **所有能调的数**：三场比赛、呼吸、吸附、对手性格、奖金 |
| `js/themes.js` | 九张背景的画法参数（加新地图在这里加一项） |
| `js/scene.js` | 按主题随机生成并画场景 |
| `js/duel.js` | 一次对狙的规则：缩头、他的红圈、锁定、开枪（以后电竞高光直接用这块） |
| `js/classic.js` | 原作玩法样机 |
| `js/team.js` | 队友、训练、基地、临场卡、存档 |
| `js/cutscene.js` | 过场动画：开场字、换点位、这场拿下、女队友拉人、网吧揭晓 |
| `js/main.js` | 流程、按钮、开场页、选卡页、战队页 |
| `js/platform.js` | 唯一碰微信 / 浏览器的地方（触摸、震动、广告、存档） |

## 改完代码以后

node tools/build-preview.js   # 重新生成 preview.html 和 index.html
