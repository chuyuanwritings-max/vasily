## 0.9 改了什么（二战样机）

- **三关**（地图页）：一队巡逻 → 两队巡逻 → 王牌（他也摆钢盔假人、扔烟雾弹）。都在废墟城镇。
- **楼下的巡逻**（`duel.js` 的 patrols，数在 `config.patrol`）：在你这栋楼下的街上来回走，抬头看楼上，扇形左右各看一扇窗。照《盟军敢死队》的两段视野：扇形里露着头，很快被发现；缩着头躲得过远的一段，正下方缩头也躲不过，要换窗。警报满了就输（「被巡逻发现了」）。
- **队友**（`config.squad`，缩头和扳机中间两个按钮，各一次）：
  - 诱饵兵：举起钢盔，他探头时朝钢盔开枪，火光把他照出来；
  - 贝雷帽：放倒离你最近的巡逻兵，那队巡逻停下来找人 15 秒，警报降一半。
- **「同时 / 轮流」切换**（地图页）：同时 = 巡逻和对面一起压过来（Cc 定的方案）；轮流 = 巡逻在楼下时对面缩着不找你（总指挥那边的建议）。给 Cc 两种都试。
- 开场页改成「二战 · 狙击手对决」。

## 0.8 改了什么（新规矩「先模仿，再改」，Cc 选模仿《Sniper 3D Assassin》、「按计划开工」）

- 先拆它的 13 关写进 `../模仿_Sniper3D_关卡拆解.md`，再照它的玩法和关卡结构做这一版。题目、人物、画面都是自己的。
- **一关**：开局一张目标卡，一句话加特征图标（如「对手穿红衣服」「通缉：红头发，提着手提箱」）。楼上窗里和街上都有人：先看全景，点一下放大到那里，按住稳住、松手开枪。
- **有颜色的人**（`js/people.js`）：衣服颜色、头发、帽子、背包 / 行李袋 / 手提箱、墨镜、手机、枪、炸弹包。街上的人会走。路人跟目标不一样，两条线索的关里有只对上一半的路人。
- **九种花样**（`js/mission.js`）：认一个人、会跑（跑出画面就输）、限时打一群、炸弹包倒计时、装成路人突然掏枪、一枪定生死（他在瞄你，可以缩头）、打车里的司机、暗处交易（看打火机的光）、先打灭灯再打人。
- **打错人**：路人吓得躲起来（没有血），扣 8 秒。**爆头**另外多给金币。
- **第一座城「沙漠土楼镇」20 关**：教学 3 + 主线 12 + 特别任务 5。第三个特别任务是「掩护小雨」，第五个是「五个狙击手」（就是原来的对狙，缩头、红圈都在）；打完第五个放网吧揭晓。
- **升级枪**（地图页）：瞄准镜（判定圈大）、枪托（稳得快）、弹匣（多一发）、枪栓（换弹快），各 5 级。临场卡、队友练级先收起来，存档不删。
- 0.7 的网吧赛九关还在代码里（`levels.js` 的 `CAFE`），不在地图上；擂台、每日挑战照旧是对狙。

## 0.7 改了什么（Cc 的环境计划，她定「城市放中间第五关」「按计划开工」）

- 十二张地图（`js/themes.js` 的 `MAP_ORDER`）。只学 CS 那类环境类型，名字、布局、长相都是自己的。
- 每张三样不一样：
  - 藏身位的样子：窗、拱窗、集装箱门、草料门、壁龛、箭孔、碉堡射击孔、玻璃格、墙上炸开的洞。箭孔和射击孔只露得出头，更难认。
  - 缩头时会变的东西：挂毯、百叶窗、箱门、草堆、藤蔓、火把、警示灯、冰溜子、百叶帘、火光、破布，以及旗子、风向标、吊钩、信号灯、烟囱、擦窗吊篮、钟。
  - 窗里的误导物：神庙、城堡里加了石头人像和陶罐。
- 楼的排法：一排楼 / 山坡 / 台阶神庙 / 城墙加塔 / 营房加瞭望塔 / 玻璃高楼。
- 地图自带的遮挡（`config.covers`）：火车、蒸汽、烟雾弹、沙尘暴、瀑布水雾、玻璃反光。
  - 挡住他那扇窗时，他看不见你，不升温、不锁定。
  - 火车还挡子弹。
  - 玻璃反光只晃你的眼，不挡他。
  - 烟雾弹扔在他附近，烟一起来就知道他大概在哪。
- 第一章九关换成九张地图；擂台、每日挑战从十二张里抽，地图自带的遮挡也一起来。Boss 在电厂，第三招放蒸汽。
- Midjourney 背景图接口：一张图 + 一份藏身位标记（`js/bgslots.js`）= 一张地图。图载到了就贴图，载不到照旧代码画。生图需求在 `生图/`。

## 0.6 改了什么（Cc 试玩 0.5 的意见）

- 删掉指方向的箭头。耳机卡、观察手小雨改成「红圈离你还远就滴滴报警」，只帮保命、不帮找人。
- 误导项：窗里加花盆、猫、台灯、人体模特、挂着的大衣、鸟笼（跟人影一样的黑剪影，打中算打错）；人影 4–8 个；有的路人拿手机，屏幕会闪（假反光）；缩一次头变 4–8 处；楼上加空调外机、阳台栏杆。
- 更难：去掉吸附；判定圈 7 → 5；他的反光更暗更短，只在红圈压到你身边一格才闪；他缩头前后的挪动更小。
- 输了：失败页写差多少，「再来」点一下直接回这一回合；被打死、子弹打光的激励视频都放在这一页。关前说明每关只看一次。
- 擂台：一个接一个打，每赢一个叠一个加难（人更多、少一发、判定圈更小、少 15 秒、他找得更快、大雾 / 夜里 / 鸽群），记最高连胜。
- 每日挑战：同一天所有人同一局（三个回合），重来也一样，比用时。
- 背景：Cc 选先拿一关试 Midjourney，图到了放进第一关；这版先加密代码画的楼。

## 怎么玩（谁先暴露谁死）

- 左下按住 = 缩头：躲在墙后最安全，但看不见、打不了。点一下 = 缩一下再起来，画面会变一处（找茬）。
- 镜子下面那栋楼是你，红圈是他的镜子。红圈停在你窗口上、你又露着头，锁定圈就转；转满了他瞄准你（镜片反光），这时要么抢先开枪，要么马上缩头。
- 红圈在动 = 他探着头在找你，这也是你唯一打得中他的时候。
- 右下按住屏息、松手开枪，只算打头。打空一枪 = 枪口火光，红圈直接跳到你身上。
- 对面有好几个人影，只有一个是狙击手：看反光、看谁不对劲（每种对手一个破绽）。打错人扣 8 秒。
- 每回合子弹有限，打空一发他换窗；整回合有倒计时。
- 点下面那栋楼的另一扇窗 = 爬过去换窗（1.5 秒），他对你位置的把握清零。同一扇窗露头三次，他就预先瞄着。
- 有声音：枪声、心跳、红圈靠近的滴滴、锁定、鸽子、金币、星星（全部代码合成，`js/sfx.js`）。

## 原作玩法样机

开场页「原作玩法样机」：照 2009 年《Sniper vs Sniper》（国内叫「狙击手对决」）那类对楼狙击手游的规则搭的，画面是我们自己的。望远镜看得宽不能开枪，狙击镜能开枪看得窄；他们探头就在瞄你，3 格血，60 秒。打完有一页说明它好玩在哪、毛病在哪。
