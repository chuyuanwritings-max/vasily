## 0.6 改了什么（Cc 试玩 0.5 的意见）

- 删掉指方向的箭头。耳机卡、观察手小雨改成「红圈离你还远就滴滴报警」，只帮保命、不帮找人。
- 误导项：窗里加花盆、猫、台灯、人体模特、挂着的大衣、鸟笼（跟人影一样的黑剪影，打中算打错）；人影 4–8 个；有的路人拿手机，屏幕会闪（假反光）；缩一次头变 4–8 处；楼上加空调外机、阳台栏杆。
- 更难：去掉吸附；判定圈 7 → 5；他的反光更暗更短，只在红圈压到你身边一格才闪；他缩头前后的挪动更小。
- 输了：失败页写差多少，「再来」点一下直接回这一回合；被打死、子弹打光的激励视频都放在这一页。关前说明每关只看一次。
- 擂台：一个接一个打，每赢一个叠一个加难（人更多、少一发、判定圈更小、少 15 秒、他找得更快、大雾 / 夜里 / 鸽群），记最高连胜。
- 每日挑战：同一天所有人同一局（三个回合），重来也一样，比用时。
- 背景：Cc 选先拿一关试 Midjourney，图到了放进第一关；这版先加密代码画的楼。

## 第一章怎么走

开场 → 章节地图（9 个关卡点，星星、段位、奖金）→ 点一关：看目标和三颗星的条件、带一张卡 → 这关新东西的说明页 → 回合卡（对手和他的破绽）→ 对狙 → 过关：星星一颗颗砸下来、金币飞进奖金栏、解锁下一关和一张新卡 → 第一次打败 Boss「老枪」：网吧揭晓 → 战队。

| 关 | 新东西 |
| --- | --- |
| 1 第一枪 | 四个人影认一个；缩头、红圈、开枪 |
| 2 谁在闪 | 六个人影；红圈压到你身边时他镜片反光；路人的手机也会闪；耐心型和人体模特都不动 |
| 3 换个窗 | 点下面的楼换窗；同一扇窗露头三次他就记住；焦躁型敲窗台 |
| 4 起雾了 | 大雾一阵一阵，浓雾时他也看不清你 |
| 5 假人 | 狡猾型的头盔假人；打错人扣 8 秒 |
| 6 掩护小雨 | 小雨在街上跑，他瞄小雨时不看你 |
| 7 鸽子 | 他探头那栋楼的鸽子会飞；换位型被盯住就换窗 |
| 8 一枪定胜负 | 夜里只有亮灯的窗看得清；每回合一发子弹 |
| Boss 老枪 | 三条命，每挨一枪换一招：不动 → 换窗 → 两个假人加大雾 |

输了：他先开枪 / 时间到 / 子弹打光 / 小雨被打中。失败页写差多少、回放他的红圈怎么找到你；被打中可以叫小雨拉起来、子弹打光可以让小雨扔一发（都是广告占位）；点「再来」直接回这一回合。

## 怎么玩（谁先暴露谁死）

- 左下按住 = 缩头：躲在墙后最安全，但看不见、打不了。点一下 = 缩一下再起来，画面会变一处（找茬）。
- 镜子下面那栋楼是你，红圈是他的镜子。红圈停在你窗口上、你又露着头，锁定圈就转；转满了他瞄准你（镜片反光），这时要么抢先开枪，要么马上缩头。
- 红圈在动 = 他探着头在找你，这也是你唯一打得中他的时候。
- 右下按住屏息、松手开枪，只算打头。打空一枪 = 枪口火光，红圈直接跳到你身上。
- 对面有好几个人影，只有一个是狙击手：看反光、看谁不对劲（每种对手一个破绽）。打错人扣 8 秒。
- 每回合子弹有限，打空一发他换窗；整回合有倒计时。
- 点下面那栋楼的另一扇窗 = 爬过去换窗（1.5 秒），他对你位置的把握清零。同一扇窗露头三次，他就预先瞄着。
- 有声音：枪声、心跳、红圈靠近的滴滴、锁定、鸽子、金币、星星（全部代码合成，`js/sfx.js`）。

## 原作玩法样机

开场页「原作玩法样机」：照 2009 年《Sniper vs Sniper》（国内叫「狙击手对决」）那类对楼狙击手游的规则搭的，画面是我们自己的。望远镜看得宽不能开枪，狙击镜能开枪看得窄；他们探头就在瞄你，3 格血，60 秒。打完有一页说明它好玩在哪、毛病在哪。

## 两层成长

| | 是什么 | 留多久 |
| --- | --- | --- |
| 临场卡 | 关前带一张，每第一次过一关解锁一张：深呼吸、好镜子、耳机（指方向）、口香糖、消音器（打空不暴露）、诱饵头盔（替你挨一枪，他的火光照出他自己）、伪装网、护身符、快手 | 这一次网吧赛 |
| 队友 | 五个人各管一种加成（稳得快 / 指方向 / 冷静 / 快枪 / 藏得好），花奖金练级，最高 5 级 | 一直有（存档） |
| 训练基地 | 网吧角落 → 训练室 → 战队基地，奖金 ×1 / ×1.25 / ×1.5 | 一直有 |

队友名字、长相都是占位，等 Cc 定用不用剧里的人。
