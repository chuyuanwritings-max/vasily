## 怎么打开

| 想在哪看 | 怎么做 |
| --- | --- |
| 电脑浏览器（最快） | 双击 `preview.html` |
| 手机浏览器 | 把 `preview.html` 发到手机打开（单文件，不用联网） |
| 微信开发者工具 / 真机 | 「导入项目」选这个 `原型` 文件夹；把 `project.config.json` 里的 `touristappid` 换成你的小游戏 AppID |

## 怎么玩

- 手指拖镜头；左下眼睛 = 眨眼找他；右下 = 按住屏息、松手开枪。
- 他会「缩着 → 探头 → 缩回去」，**只有探头时打得中，而且只算打头**。
- 屏息要按住 0.9 秒左右才稳，稳 2 秒后开始手抖：要读他的节奏，提前按住。
- 每一枪都留弹孔，提示「偏了 / 差一点 / 他缩着」；打空会暴露位置。
- 上方镜片满了 = 他找到你了；他下一次探头就开枪，镜子边缘变红，谁先开枪谁赢。
- 三个对手性格不同：耐心型（探得少但久）、焦躁型（探得勤缩得快）、狡猾型（会假探头）。
- 被打中可以「叫队友拉你」一次（现在是 3 秒广告占位）。

## 文件

| 文件 | 管什么 |
| --- | --- |
| `game.js` / `game.json` / `project.config.json` | 微信小游戏入口和设置 |
| `js/config.js` | **所有能调的数**（眨眼黑屏多久、干扰几个、对面多快、呼吸、心跳、开枪窗口） |
| `js/duel.js` | 一次对狙的规则（以后电竞高光直接用这块） |
| `js/scene.js` | 随机生成场景和画法（分层透视、美漫网点） |
| `js/main.js` | 一关的流程、按钮、动画、女队友拉人 |
| `js/platform.js` | 唯一碰微信 / 浏览器的地方 |

## 改完代码以后

```
node tools/build-preview.js   # 重新生成 preview.html
node test/wx-smoke.js         # 在假的微信环境里跑一遍（确认没用网页才有的东西）
node test/robot.js            # 机器人把一关从头点到尾，截图在 test/shots/
```

`tools/`、`test/`、`preview.html` 不会打进微信包（见 project.config.json 的 packOptions）。

## 没做（按游戏计划 1.0 的原型范围）

美术定稿、卡牌、局外成长、双人、真广告、开场动画（现在是一张漫画格占位）、陀螺仪。
